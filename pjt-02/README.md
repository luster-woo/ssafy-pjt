단계별 구현 과정 및 학습 내용

1. 데이터 전처리 단계

처음에는 전체 주가 데이터 중에서 2022년 1월 이후 데이터만 분석 대상으로 사용하였다.  
Pandas를 이용해 Date 컬럼을 기준으로 조건 필터링을 수행하였으며,  
이 과정에서 원하는 기간의 데이터만 추출하는 방법을 다시 익힐 수 있었다.

필터링 후 데이터프레임을 다룰 때 copy()를 사용하지 않으면 경고 메시지가 발생할 수 있다는 점을 알게 되었고,  
이를 통해 데이터 전처리 과정에서 안전하게 데이터를 처리하는 방법의 중요성을 이해하게 되었다.

2. 데이터 정렬 및 시각화 준비

날짜 데이터를 기준으로 그래프를 그리기 위해 Date 컬럼을 기준으로 데이터를 정렬하였다.  
정렬을 하지 않았을 경우 그래프의 흐름이 자연스럽지 않게 나타날 수 있다는 점을 직접 확인하면서,  
시계열 데이터에서는 정렬이 필수적이라는 점을 학습하였다.

또한 모든 날짜를 x축에 표시하면 가독성이 떨어지기 때문에,  
일정 간격으로 날짜를 선택하여 x축 눈금으로 표시하는 방법을 적용하였다.

3. 그래프 시각화 단계

Matplotlib을 사용하여 High, Low, Close 가격을 하나의 그래프에 시각화하였다.  
여러 개의 선이 동시에 표시되면서 범례와 축 레이블의 중요성을 느낄 수 있었고,  
그래프 제목을 통해 어떤 내용을 나타내는 그래프인지 명확히 전달하려고 하였다.

이 과정에서 단순히 그래프를 그리는 것에서 끝나는 것이 아니라,  
그래프가 데이터를 제대로 표현하고 있는지 확인하는 습관의 필요성을 느꼈다.

4. 데이터 해석 및 분석 단계

완성된 그래프를 바탕으로 주가의 전반적인 흐름을 해석하였다.  
2022년 1월 이후 Netflix 주가는 전반적으로 하락하는 모습을 보였으며,  
이는 단기적인 변동이 아닌 추세적인 하락으로 판단할 수 있었다.

또한 주가 변화의 원인을 분석하기 위해 당시 Netflix의 기업 이슈와  
금리 인상과 같은 거시경제 상황을 함께 고려하였다.  
이를 통해 데이터 분석은 숫자만 보는 것이 아니라,  
현실적인 배경과 함께 해석해야 한다는 점을 알게 되었다.

어려웠던 부분

그래프를 그리는 것 자체보다는,  
그래프를 근거로 논리적인 설명을 작성하는 과정이 가장 어려웠다.  
또한 날짜 데이터 처리와 시각화 과정에서 발생하는 작은 오류들을  
하나씩 수정하는 데 시간이 필요했다.

새로 배운 점

Pandas를 활용한 조건 필터링 방법과 copy()의 필요성,  
시계열 데이터에서 정렬이 왜 중요한지에 대해 명확히 이해하게 되었다.  
또한 시각화 결과를 기반으로 추세를 분석하고,  
이를 실제 경제 및 산업적 배경과 연결해 설명하는 방법을 새롭게 배울 수 있었다.

느낀 점

이번 과제를 통해 데이터 분석은 단순히 코드를 작성하는 작업이 아니라,  
데이터를 해석하고 설명하는 능력이 함께 필요하다는 것을 느꼈다.  
특히 시각화된 결과를 보고 의미를 도출하는 과정이 인상 깊었으며,  
앞으로 데이터 분석을 할 때 더 신중하게 접근해야겠다고 생각하게 되었다.
