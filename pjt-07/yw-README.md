💡 회고 및 느낀점
이번 프로젝트는 단순히 API를 호출하는 것을 넘어, '데이터를 서비스에 맞게 어떻게 가공할 것인가'를 깊게 고민해 본 시간이었습니다.

처음엔 공공데이터 API만 연동하면 수월하게 진행될 줄 알았습니다. 하지만 실제로는 줄글로 된 우대조건 텍스트를 시스템이 계산할 수 있도록 구조화하고 전처리하는 과정이 생각보다 훨씬 까다로웠습니다. 원하는 추천 결과를 얻기 위해 데이터를 정제해 나가면서, 백엔드 로직에서 데이터 파이프라인 설계가 얼마나 중요한지 실감했습니다.

가장 기억에 남는 것은 '거리 기반 가산점' 로직을 구현한 부분입니다. 공공데이터의 지점 주소를 카카오 로컬 API를 통해 위경도로 변환하고, 하버사인 공식을 적용해 내 반경 내의 은행을 찾는 과정을 직접 코드로 짜보면서 큰 성취감을 느꼈습니다.

또한, 짧은 기간 안에 프론트엔드와 백엔드를 나눠서 개발하다 보니 소통의 중요성을 뼈저리게 느꼈습니다. 진웅 님과 개발 초기에 API 명세서와 데이터 규격을 꼼꼼하게 맞춰둔 덕분에 데이터 연동 과정에서의 병목을 크게 줄일 수 있었습니다.

시간 관계상 데이터 수집 스케줄링을 완벽하게 자동화하지 못한 점이나 쿼리 최적화 부분은 아쉬움으로 남습니다. 하지만 기획했던 '개인화된 금융 의사결정 지원'이라는 목표를 실제 동작하는 서비스로 구현해 냈다는 점에서 아주 의미 있는 프로젝트였습니다. 다음 프로젝트에서는 이번에 느낀 한계점들을 보완하여 아키텍처를 한 단계 더 발전시켜보고 싶습니다.
