# 🧭 Fin-Navigator (금융 내비게이터)

> **1020 금융 초보자를 위한 개인화 맞춤형 예·적금 비교 및 의사결정 지원 플랫폼**

## 1. 프로젝트 개요

* **목표** : 정보 비대칭과 복잡한 금융 용어로 어려움을 겪는 1020 세대에게 직관적인 금융 상품 비교 및 개인 맞춤형 추천 서비스를 제공합니다.
* **타겟** : 금융 상품 선택에 어려움을 느끼는 사회 초년생 및 학생 (10대 후반 ~ 20대 후반).
* **핵심 가치** : 데이터 통합, 개인화 스코어링, 직관적 시각화, 신뢰 기반의 추천 근거 제공.

## 2. 개발 환경 및 스택

* **Backend** : Python, Django,
* **Frontend** :  Vue, Js
* **Database** : SQLite
* **API** : 금융위원회
  한국예탁결제원
  예금보험공사
  금융감독원
  한국은행
* **Tools** : ERDCloud, Figma

## 3. 주요 기능

| **구분**    | **기능명**  | **상세 내용**                                      |
| ----------------- | ----------------- | -------------------------------------------------------- |
| **Data**    | 상품 목록 및 검색 | 금감원 API 기반 예·적금 통합 리스트 출력 및 필터링      |
| **Auth**    | 회원 관리         | JWT 기반 회원가입 및 로그인, 사용자 프로필 관리          |
| **Core**    | 성향 분석         | 폼 입력을 통한 사용자 금융 성향(투자 기간, 목표 등) 파악 |
| **Algo**    | 맞춤형 추천       | 성향 데이터 기반 상품별 가중치 스코어링 및 근거 시각화   |
| **Social**  | 커뮤니티          | 유저 간 정보 공유를 위한 게시판 및 댓글 기능            |
| **Utility** | 내 지갑           | 관심 상품 북마크 및 개인화된 자산 목표 관리              |

## 4. 데이터베이스 구조

프로젝트는 크게  **사용자(User)** ,  **상품(Product/Option)** ,  **커뮤니티(Article)** , **매핑(Wallet)** 구조로 설계되었습니다.

* **User** : 성향 점수 및 목표 데이터를 포함한 사용자 정보.
* **Product & Option** : 1:N 관계로 설계하여 하나의 상품에 대한 다양한 기간별 금리 정보를 관리.
* **Article** : 유저와 1:N 관계로 연결된 커뮤니티 게시글.
* **Wallet** : 유저와 상품을 연결하는 M:N 중계 테이블로 관심 상품 관리.

## 5. 프로젝트 일정

5일간의 집중 스프린트로 진행됩니다.

* **Day 1** : 요구사항 정의, API 명세 작성, ERD 및 화면 설계 (기획 완료)
* **Day 2** : 백엔드 데이터 크롤링/파싱 로직 개발 및 DB 기본 구축
* **Day 3** : 스코어링 알고리즘 구현 및 프론트엔드 핵심 UI 개발
* **Day 4** : 프론트-백엔드 API 연동 및 추천 결과 시각화(Chart.js) 작업
* **Day 5** : 통합 테스트, 디버깅 및 포트폴리오 산출물 정리
