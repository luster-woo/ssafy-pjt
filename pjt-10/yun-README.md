## 어려웠던 점

처음 카카오맵 API를 연동하는 과정에서 API 키 설정과 도메인 등록 문제로 오류가 발생하여 해결하는 데 시간이 걸렸다. 또한 지도에 마커를 표시하고 사용자가 선택한 위치까지의 경로를 시각적으로 표현하는 과정이 생각보다 복잡하게 느껴졌다.

## 재미있었던 점

단순히 데이터를 출력하는 것이 아니라 실제 지도를 활용하여 원하는 은행 위치를 찾고, 경로까지 표시되는 모습을 확인할 때 가장 재미있었다. 웹 페이지가 실제 서비스처럼 동작하는 것을 보면서 성취감을 느낄 수 있었다.

## 느낀 점

외부 API를 활용하면 다양한 기능을 직접 구현하지 않아도 사용할 수 있다는 점을 알게 되었다. 또한 API 문서를 참고하며 필요한 기능을 구현하는 경험을 통해 문서를 읽고 적용하는 능력의 중요성을 느꼈다. 앞으로도 다양한 API를 활용하여 더 많은 서비스를 만들어 보고 싶다.
