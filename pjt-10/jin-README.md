## 💡 주요 기능 구현

1. **카카오 지도 출력 (F1002)**
   - API를 호출하여 강남역(37.49818, 127.027386)을 초기 중심 좌표로 하는 지도 렌더링.
2. **동적 3단계 드롭다운 UI (F1003)**
   - 로컬 `data.json` 파일을 비동기(`fetch`)로 불러와 '광역시/도 -> 시/군/구 -> 은행명' 순으로 선택할 수 있는 동적 Select Box 구현.
3. **은행 검색 및 마커/인포윈도우 표시 (F1004)**
   - 사용자가 선택한 조건에 맞는 은행 지점을 지도 위에 마커로 표시.
   - 마커 클릭 시 해당 지점의 이름과 주소가 포함된 인포윈도우 출력 기능.
4. **[심화] 카카오 모빌리티 길찾기 연동 (F1011)**
   - 출발지(멀티캠퍼스 역삼)에서 선택한 은행 마커 위치까지의 자동차 이동 경로(Polyline) 시각화.
   - 주행 거리 및 예상 소요 시간 계산 후 화면 하단 상태 표시줄에 출력.

## 트러블 슈팅 (어려웠던 점 및 해결 과정)

### 1. 카카오 API 도메인 불일치로 인한 스크립트 로드 실패

- **문제:** Live Server 환경에서 지도를 띄울 때 `127.0.0.1` 주소에서 API 호출이 차단되는 문제 발생.
- **원인:** Kakao Developers 플랫폼 웹 도메인 설정에 `localhost:5500`과 `127.0.0.1:5500`이 엄격하게 구분되어 인식됨.
- **해결:** 브라우저 주소창의 실행 도메인과 디벨로퍼스에 등록된 Web 플랫폼 도메인을 정확히 일치시키고, 포트 번호 끝의 슬래시(`/`)를 제거하여 권한(401) 에러 해결.

### 2. 존재하지 않는 DOM 요소 참조로 인한 JavaScript 크래시

- **문제:** HTML 구조를 변경(텍스트 입력창 -> Select Box, 리스트 UI 제거)한A 후, 스크립트가 실행 도중 멈추며 데이터가 화면에 그려지지 않음.
- **원인:** JS 파일에서 삭제된 HTML 요소(`bankList` 등)에 `innerHTML`이나 `appendChild`를 시도하여 `null` 참조 에러 발생. 에러가 발생한 시점에서 스크립트가 종료되어 하위 로직이 실행되지 않음.
- **해결:** DOM 요소를 조작하기 전, 해당 요소가 존재하는지 확인하는 방어 코드(`if (!element) return;`)를 추가하여 프로그램이 비정상 종료되는 것을 방지함.

### 3. Kakao Mobility API 통신 방식 변경

- **문제:** 심화 기능인 길찾기 로직 실행 시, 경로를 찾지 못하고 직선으로만 표시되는 현상 발생.
- **원인:** 스켈레톤 코드의 라우팅 로직이 로컬 백엔드 서버(포트 3000)를 거치도록 설계되어 있었으나, 현재 프론트엔드 단독 프로젝트 환경이므로 통신 실패.
- **해결:** 중간 서버를 거치지 않고 JS 파일 내부에서 곧바로 Kakao Mobility REST API(`apis-navi.kakaomobility.com`)를 호출하도록 로직 전면 수정. 헤더에 `Authorization: KakaoAK {REST_API_KEY}`를 담아 GET 요청을 보내고, 응답받은 `vertexes` 데이터를 파싱하여 지도상에 Polyline을 정상적으로 그림.

## 학습한 내용 및 느낀 점.

- HTML과 JavaScript는 긴밀하게 연결되어 있어, 하나의 UI 요소가 변경되거나 누락되었을 때 전체 스크립트가 멈출 수 있다는 것을 경험
- 외부 API를 사용할 때는 구글링에 의존하기보다, 제공된 공식 가이드와 Documentation을 꼼꼼히 확인하고 요구하는 Request Parameter와 Headers 형식을 정확히 맞추는 것이 가장 빠른 해결책임을 느낌
