# 📈 투자자 댓글 수집·정제 서비스 (PJT 06)

**Django**와 **Selenium**으로 토스증권 커뮤니티 댓글을 수집하고, **Pandas**로 정제한 뒤 원본·정제·증강 단계별 결과를 저장하는 웹 서비스입니다.

## 🚀 주요 구현 기능

*   **동적 페이지 크롤링**: Selenium(headless)으로 토스증권에서 회사명을 검색해 종목 페이지로 이동하고, 커뮤니티 댓글을 스크롤하며 최대 20개를 수집합니다. 화면 구조가 바뀌어도 동작하도록 검색창·댓글 셀렉터를 여러 후보로 두고 순서대로 시도합니다.
*   **데이터 정제**: 특수문자를 지운 뒤 숫자만·`ㅋㅎ`만·영문만으로 된 댓글과 부적절한 표현이 들어간 댓글을 걸러냅니다. 이어서 댓글 길이의 **IQR**(Q1 − 1.5·IQR ~ Q3 + 1.5·IQR, 하한은 최소 5자)로 지나치게 짧거나 긴 이상치를 제거합니다. 남은 댓글이 5개 미만이면 IQR 대신 3자 이상만 남깁니다.
*   **규칙 기반 증강**: 댓글에 '상승·기대' 또는 '하락·매도' 같은 키워드가 있는지에 따라 정해진 문장을 덧붙여 증강 데이터를 만듭니다. (LLM은 사용하지 않았습니다.)
*   **단계별 저장**: 검색어, 매칭된 종목명·종목 코드, 원본·정제·증강 댓글, IQR 상·하한을 한 번의 실행 단위(`CommentRun`)로 DB에 저장하고 최근 5건을 화면에 보여줍니다.

## 🛠️ 개발 중 직면한 문제 및 대처

*   **동적 웹 요소의 로딩 시점 불일치**: 토스증권의 검색창과 커뮤니티 댓글이 나타나는 시점이 일정하지 않아 크롤러가 요소를 찾지 못하고 **TimeoutException**이 발생했습니다.
    *   **대처**: `WebDriverWait`와 `expected_conditions`로 **명시적 대기**를 걸고, 종목 페이지 이동은 URL이 바뀌는 것을 기다려 확인했습니다. 셀렉터는 후보를 순서대로 시도해 하나가 실패해도 다음 후보로 넘어가게 했습니다.
*   **상호 참조(Circular Import) 에러**: `views.py`와 `services.py` 사이에서 함수를 서로 참조하려다 모듈을 로드하지 못하는 **ImportError**가 발생했습니다.
    *   **대처**: 크롤링·정제·증강 로직을 `services.py`로 모두 옮기고, `views.py`는 이를 호출만 하는 **단방향 구조**로 바꿔 해결했습니다.

## 📝 느낀 점

*   **수집보다 정제가 어려웠습니다**: 수집한 댓글에는 의미 없는 짧은 반응과 특수문자가 많았습니다. 패턴 필터로 먼저 거르고 길이 분포(IQR)로 한 번 더 거르는 식으로 단계를 나누니, 남는 데이터의 질이 눈에 띄게 달라졌습니다.
*   **예외는 사용자 메시지로**: 타임아웃·종목 없음 같은 크롤링 실패를 하나의 예외로 모아 화면에 안내 문구로 보여주도록 했습니다.
