# 관심 종목 영상 검색 서비스

Vue 3와 YouTube Data API를 이용해서 관심 있는 동영상을 검색하고, 상세 보기 및 저장 기능을 구현한 간단한 프로젝트입니다.

## 주요 기능

- 검색어로 YouTube 영상 검색
- 검색 결과 카드 형태 출력
- 영상 상세 페이지에서 동영상 재생
- `나중에 볼 영상` 저장/삭제
- `좋아하는 채널` 저장/삭제
- 챗봇 형태로 자연어 명령 실행


## 느낀 점

- Vue 3와 라우터를 이용해 화면 전환을 구현하면서 SPA 구조가 더 잘 이해되었습니다.
- UI를 예시 화면에 맞추는 과정에서 Bootstrap과 CSS 스타일링을 실습할 수 있었습니다.

## 어려웠던 점

- YouTube API를 통해 필요한 영상과 채널 정보를 정확하게 가져오는 부분이 생각보다 까다로웠습니다.
- 챗봇 명령을 자연어로 해석하는 로직을 간단하게 구성하는 데 시간이 걸렸습니다.
