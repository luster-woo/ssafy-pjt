💰 금융 자산 정보 토론 게시판 서비스 (PJT 05)
이번 프로젝트에서는 Django의 기본 인증 시스템을 확장하여 사용자 맞춤형 정보를 관리하고, 실제 JSON 데이터를 연동한 회원가입 및 프로필 기능을 구현하였습니다.

🚀 주요 구현 기능
커스텀 유저 모델 확장: Django의 AbstractUser를 상속받아 nickname, interest_stocks, profile_image 필드를 추가하여 개인화된 사용자 정보를 관리할 수 있게 설계했습니다.

동적 데이터 연동: assets.json 파일에 저장된 금융 자산 데이터를 실시간으로 로드하여 회원가입 시 관심 종목을 선택할 수 있는 체크박스 기능을 구현했습니다.

인증 시스템 완성: 회원가입 시 자동 로그인, 비밀번호 변경(Password Change), 로그아웃 및 성공 메시지 알림 등 사용자 편의를 고려한 인증 프로세스를 구축했습니다.

프로필 페이지: 사용자가 작성한 게시글을 username 기반으로 필터링하여 노출하고, 본인의 활동 내역과 관심 자산을 한눈에 확인할 수 있도록 구성했습니다.

🛠 개발 중 직면한 문제 및 대처
다중 선택 데이터 저장 로직: 관심 종목(Multiple Choice) 데이터를 데이터베이스의 단일 텍스트 필드에 어떻게 저장할지 고민했습니다.

대처: forms.py의 save 메서드를 오버라이딩하여 리스트 데이터를 쉼표(,)로 구분된 문자열로 변환(Join)해 저장하고, 템플릿에서 다시 분리(Split)하여 출력하는 방식으로 해결했습니다.

URL 설정 및 404 에러: 앱 분리 과정에서 accounts/ 경로 설정이 꼬여 페이지를 찾지 못하는 문제가 발생했습니다.

대처: 프로젝트의 urls.py와 앱의 urls.py 구조를 계층적으로 재정비하고, name 인자를 활용한 리다이렉트 경로를 통일하여 해결했습니다.

📝 느낀 점
유연한 모델 설계의 중요성: Django가 제공하는 기본 기능을 그대로 쓰기보다, 프로젝트 목적에 맞게 모델과 폼을 커스텀하는 과정에서 프레임워크의 높은 자유도를 체감할 수 있었습니다.

데이터 가공 역량: 외부 파일(JSON)을 읽어와 Django 폼 위젯으로 변환하는 과정을 통해, 백엔드에서 데이터를 가공하여 프론트엔드로 전달하는 전체적인 데이터 흐름을 깊이 있게 이해하게 되었습니다.

보안 및 세션 관리: 비밀번호 변경 후에도 사용자의 로그인이 유지되도록 세션 해시를 업데이트하는 등 실제 서비스에서 고려해야 할 디테일한 보안 로직을 배울 수 있는 유익한 시간이었습니다.
