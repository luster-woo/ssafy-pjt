# pjt-05 금융 자산 커뮤니티

## 1. 프로젝트 소개
이번 프로젝트는 Django를 활용해서 금융 자산별 게시판과 사용자 기능을 구현하는 과제입니다.  
회원가입, 로그인, 로그아웃, 비밀번호 변경, 게시글 작성/수정/삭제, 프로필 조회 기능을 구현했고, 심화 기능으로 LLM 기반 투자 성향 분석도 추가했습니다.

## 2. 구현 기능
- 커스텀 유저 모델 구현
- 회원가입 / 로그인 / 로그아웃 / 비밀번호 변경
- 자산 목록 조회 및 자산별 게시글 조회
- 게시글 작성, 수정, 삭제
- 작성자 본인만 수정/삭제 가능하도록 권한 처리
- 프로필 페이지에서 닉네임, 관심 종목, 작성한 게시글 확인
- 투자 성향 분석 기능 구현

## 3. 어려웠던 점과 느낀 점
가장 어려웠던 부분은 커스텀 유저 모델을 적용하는 과정이었습니다. 기본 User 모델 대신 새로운 모델을 연결해야 해서 `settings.py`, `models.py`, 마이그레이션 흐름을 같이 이해해야 했습니다.

또 게시글 권한 처리도 생각보다 헷갈렸습니다. 처음에는 화면에서 버튼만 숨기면 된다고 생각했지만, 실제로는 `views.py`에서도 작성자 본인인지 다시 검사해야 한다는 점을 배웠습니다.

심화 기능인 투자 성향 분석은 API 연결과 `.env` 설정이 가장 어려웠습니다. 그래도 이번 프로젝트를 하면서 Django의 전체 흐름과 외부 API를 프로젝트에 연결하는 방법을 조금 더 익힐 수 있었습니다.
