# 프로필 페이지 구현 과정 정리

## 1. 구현하면서 학습한 내용

이번 과제를 통해 Bootstrap을 이용해 웹 페이지 레이아웃을 구성해 보는 연습을 했다. 이전에는 CSS로 직접 정렬을 맞추는 경우가 많았는데, Bootstrap의 `container`, `row`, `col` 구조를 사용하니까 화면을 나누는 것이 훨씬 편했다.

`col-md-5`, `col-md-7` 같은 컬럼을 사용해서 왼쪽에는 프로필 사진과 자기소개 영역을 두고, 오른쪽에는 입력 폼을 배치하는 방식으로 레이아웃을 구성했다. Bootstrap을 사용하니까 기본 스타일이 적용되어 있어서 버튼이나 입력창을 따로 꾸미지 않아도 전체적으로 깔끔하게 보였다.

또 `form-control`, `form-check`, `input-group` 같은 클래스를 사용하면서 입력창, 체크박스, 라디오 버튼 등을 정리해서 배치하는 방법도 알게 되었다.

## 2. 구현하면서 어려웠던 부분

처음 레이아웃을 만들 때는 요소들이 원하는 위치에 잘 정렬되지 않았다. 특히 프로필 영역과 입력 폼 영역을 한 줄에 배치하는 과정에서 구조가 조금 헷갈렸다.

그래서 `div` 구조를 여러 번 수정하면서 다시 정리했고, `row` 안에서 `col`로 영역을 나누는 방식으로 구성하니까 원하는 형태로 배치할 수 있었다.

또 Bootstrap 클래스가 생각보다 많아서 어떤 것을 사용해야 할지 처음에는 헷갈렸지만, 필요한 부분은 문서를 찾아보면서 하나씩 적용해 보았다.

## 3. 새로 알게 된 점

이번 과제를 하면서 Bootstrap의 그리드 시스템을 직접 사용해 볼 수 있었다. `container → row → col` 구조로 레이아웃을 구성하면 화면을 정리하기가 훨씬 편하다는 것을 알게 되었다.

또 `input-group`을 사용하면 입력창과 버튼을 한 줄로 묶을 수 있고, `form-check-inline`을 사용하면 체크박스나 라디오 버튼을 가로로 정렬할 수 있다는 것도 알게 되었다.

## 4. 느낀 점

Bootstrap을 처음 사용할 때는 클래스 이름이 많아서 조금 복잡하게 느껴졌지만, 실제로 사용해 보니 기본적인 UI를 빠르게 만들 수 있어서 편리했다.

이번 과제를 통해 웹 페이지 레이아웃을 구성하는 방법을 연습할 수 있었고, Bootstrap을 활용하면 CSS를 많이 작성하지 않아도 비교적 깔끔한 화면을 만들 수 있다는 것을 느꼈다.
