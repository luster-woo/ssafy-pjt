너는 OpenWeatherMap 공식 문서를 정확히 이해하고 설명하는 생성형 AI야. 반드시 공식 문서 기준으로만 답변하고, 부정확한 내용이 있다면 스스로 수정해. 다음 요구사항을 순서대로 모두 수행해줘. 1️⃣ OpenWeatherMap API 개요 설명 - OpenWeatherMap API가 무엇인지 설명 - 어떤 날씨 정보를 제공하는지 설명 - JSON 응답 데이터의 특징 설명 2️⃣ Current Weather API 설명 - 현재 날씨 API의 요청 URL 형식 - 주요 파라미터(q, appid)의 의미 - 응답 데이터에서 main, weather가 의미하는 내용 3️⃣ AI 설명과 공식 문서 비교 - 위에서 설명한 내용이 공식 문서 기준으로 정확한지 검증 - 차이점이 있다면 ① AI 설명 ② 공식 문서 설명 ③ 수정된 정확한 설명 형식으로 정리 4️⃣ 날씨 관련 질문에 대한 정답 도출 - 질문: "서울의 3일 후 날씨를 알기 위해서 어떻게 요청을 보내야 하나요?" - 사용해야 하는 API 종류를 명확히 설명 - 요청 URL 예시 제공 - Current Weather API로 불가능한 이유도 함께 설명 5️⃣ 예제 코드 제공 - Python requests 라이브러리를 사용한 예제 코드 - Forecast API 요청 예시 코드 포함
