📌 1️⃣ OpenWeatherMap API 개요

OpenWeatherMap API는 전 세계의 날씨 정보를 제공하는 REST API 서비스입니다.
HTTP 요청을 보내면 JSON 형태의 응답 데이터로 날씨 정보가 반환됩니다. JSON 데이터는 구조화된 key/value 쌍으로 되어 있어 프로그램에서 쉽게 처리할 수 있습니다.

OpenWeatherMap에서 제공하는 날씨 데이터 종류는 다음과 같습니다:

현재 날씨 정보

단기 예보 / 장기 일별 예보

기상 경보

기후 데이터 및 과거 데이터 등 (유료 옵션 포함)

📌 2️⃣ Current Weather API 설명
✏️ 요청 URL 형식

현재 날씨 API 호출 기본 형식은 다음과 같습니다:

https://api.openweathermap.org/data/2.5/weather?q={city name}&appid={API key}


또는 좌표로 요청할 수도 있습니다:

https://api.openweathermap.org/data/2.5/weather?lat={lat}&lon={lon}&appid={API key}


이 때 q는 도시 이름이고, appid는 개인 API 키입니다.

📌 3️⃣ 주요 파라미터 의미
파라미터	의미
q	도시 이름을 지정
appid	OpenWeatherMap API Key
lat / lon	위도/경도를 이용한 위치 지정
units	결과 단위 설정(예: metric=섭씨)
lang	응답 언어 설정
📌 4️⃣ 응답 데이터에서 main과 weather 의미
📍 main

main은 현재 기온, 체감온도, 습도, 기압 같은 날씨의 기본 수치 정보를 포함합니다.

예:

"main": {
  "temp": 298.15,
  "feels_like": 297.32,
  "pressure": 1012,
  "humidity": 60
}

📍 weather

weather는 날씨 상태(비, 맑음, 구름 등)와 그 설명 및 아이콘 코드를 포함하는 배열입니다.

예:

"weather": [{
  "id": 800,
  "main": "Clear",
  "description": "clear sky",
  "icon": "01d"
}]


이렇게 현재 날씨 상태를 나타냅니다.

📌 5️⃣ AI 설명과 공식 문서 비교
🔎 AI 설명 요약

OpenWeatherMap은 전 세계 날씨 정보를 제공한다.

q, appid 같은 주요 파라미터로 요청한다.

JSON 응답에 main과 weather로 날씨 정보를 받는다.

📘 공식 문서 기준

OpenWeatherMap 공식 문서에서도 동일하게:

현재 날씨, 예보를 제공함이 명시되어 있고

JSON 포맷이 기본임이 확인됨

수정된 정확한 설명

현재 날씨 API는 단기 예보가 아니라 현재 시점 날씨만 제공

장기 예보(일주일 등)는 다른 API를 사용해야 함

📌 6️⃣ 서울 / 부산 같은 도시의 미래 날씨 조회
🛑 Current Weather API로는 일주일 후 날씨는 제공되지 않습니다.

이는 현재 시점을 기준으로 한 정보만 반환하기 때문입니다.

📌 7️⃣ 미래 날씨(일주일 후) 요청하는 방법
☁️ (1) One Call API 3.0 이용 (공식 문서 기반 – 장기 예보 기능 포함)

One Call API 3.0은 최대 8일치 일별 예보를 제공합니다.

📍 요청 예시
https://api.openweathermap.org/data/3.0/onecall?lat={lat}&lon={lon}&appid={API_KEY}


위도/경도를 이용해야 하며,

daily 배열로 일주일(8일) 예보가 포함됩니다.

예:

import requests

lat = 35.1796  # 부산 위도
lon = 129.0756 # 부산 경도
api_key = "YOUR_API_KEY"

url = f"https://api.openweathermap.org/data/3.0/onecall?lat={lat}&lon={lon}&appid={api_key}"
response = requests.get(url)
data = response.json()
print(data["daily"][7])  # 7일 후 일별 예보

📌 8️⃣ 추가 예제: Forecast API(기간 예보)
📍 5일 / 3시간 예보 API
https://api.openweathermap.org/data/2.5/forecast?q=Busan,KR&appid={API_KEY}


이 API는 3시간 간격 5일 예보를 제공하며,
일주일 전체를 커버하기 어렵지만 단기 예보 값을 확인할 수 있습니다.

📌 정리
목적	사용해야 하는 API
현재 날씨	Current Weather API (/weather)
3~5일 예보	Forecast API (/forecast)
7일 이상 장기 예보	One Call API 3.0 (onecall)
📌 결론: “부산의 일주일 후 날씨”

Current Weather API로는 알 수 없고,
OpenWeatherOne Call API나 장기 예보 API를 사용해야 정확한 데이터를 얻을 수 있습니다.
