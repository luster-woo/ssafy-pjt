1. 과제 개요

이번 과제에서는 금융상품통합비교공시 API를 활용해
정기예금 및 적금 상품 데이터를 조회하고,
응답으로 받은 JSON 데이터를 파이썬으로 가공하여 출력했다.

또한 생성형 AI를 사용해 API 사용법을 질문하고,
AI가 제공한 설명이 공식 문서와 일치하는지도 함께 확인했다.

2. 개발 환경

Python 3

requests 라이브러리

금융상품통합비교공시 API

생성형 AI (ChatGPT)

3. 구현 내용
3.1 API 응답 구조 확인

API 응답 데이터를 그대로 출력해
전체 구조와 key 값을 먼저 확인했다.

이 과정에서 모든 주요 데이터가
result 안에 포함되어 있고,
상품 정보는 baseList, 금리 정보는 optionList에
나뉘어 있다는 것을 알 수 있었다.

3.2 데이터 추출 및 가공

과제 요구사항에 맞게
정기예금 상품 목록과 옵션 정보를 각각 추출했다.

이후 금융상품 코드를 기준으로
상품 정보와 금리 옵션 정보를 매칭해
하나의 상품에 여러 금리 옵션이 포함되도록 구성했다.

4. 생성형 AI 활용

생성형 AI를 사용해
금융상품통합비교공시 API의 구조와 사용 방법을 확인했다.

하지만 AI의 설명이 항상 정확하지 않을 수 있어
공식 문서를 직접 확인하며 비교했다.

이 과정을 통해
API 사용 시 공식 문서를 기준으로 판단해야 한다는 점을 알게 됐다.

5. 배운 점 및 느낀 점

API는 응답 구조를 먼저 파악하는 것이 중요하다

JSON 데이터는 중첩 구조로 되어 있어 단계별 접근이 필요하다

생성형 AI는 참고 도구일 뿐, 최종 기준은 공식 문서다

금융 상품 데이터는 옵션 비교가 핵심이다
