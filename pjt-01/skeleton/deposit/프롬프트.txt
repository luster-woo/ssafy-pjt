너는 금융상품통합비교공시 API 공식 문서를 정확히 이해하고 설명하는 생성형 AI야.
반드시 금융감독원 금융상품통합비교공시 공식 문서 기준으로만 답변하고,
부정확한 내용이 있다면 스스로 검증 후 수정해서 설명해야 해.

다음 요구사항을 순서대로 모두 수행해줘.

1️⃣ 금융상품통합비교공시 API 개요 설명
- 금융상품통합비교공시 API가 무엇인지 설명
- 어떤 금융상품 정보를 제공하는지 설명 (예: 예금, 적금, 대출 등)
- API 응답 데이터(JSON)의 전체 구조와 특징 설명

2️⃣ 정기적금(또는 적금) API 설명
- 적금 상품 조회 API의 요청 URL 형식 설명
- 주요 요청 파라미터(auth, topFinGrpNo, pageNo 등)의 의미 설명
- 응답 데이터에서 result, baseList, optionList가 각각 의미하는 내용 설명

3️⃣ AI 설명과 공식 문서 비교 및 검증
- 위에서 설명한 내용이 금융상품통합비교공시 공식 문서 기준으로 정확한지 검증
- 차이점이나 오해의 소지가 있는 부분이 있다면 아래 형식으로 정리
  ① AI 설명
  ② 공식 문서 설명
  ③ 수정된 정확한 설명

4️⃣ 금융상품 관련 질문에 대한 정답 도출
- 질문: "금리가 가장 높은 적금 상품을 가져오려면 어떻게 해야 하나요?"
- 사용해야 하는 API 종류를 명확히 설명
- 요청 URL 예시 제공
- 응답 데이터 중 어떤 항목을 기준으로 금리를 비교해야 하는지 설명
- 예상되는 결과 형태 예시 설명

5️⃣ 예제 코드 제공
- Python requests 라이브러리를 사용한 예제 코드 작성
- 적금 상품 조회 API 요청 코드 포함
- 응답 데이터에서 금리 정보를 추출하는 예시 코드 포함

모든 답변은 금융 API를 처음 접하는 사람도 이해할 수 있도록
단계적으로, 용어 설명을 포함하여 작성해줘.
