금융 상품 조회 API 프로젝트

프로젝트 소개
금융감독원 Open API를 활용하여 예금 상품 데이터를 저장하고 조회하는 Django REST Framework 기반 프로젝트입니다.  
예금 상품 정보와 옵션 데이터를 DB에 저장하고 다양한 조회 기능을 구현했습니다.

구현 기능
- 금융 상품 데이터 저장
- 전체 상품 조회
- 상품 추가 기능
- 특정 상품 옵션 조회
- 최고 금리 상품 조회

프로젝트를 하며
이번 프로젝트를 진행하면서 DRF의 Serializer와 APIView 사용 방식에 익숙해질 수 있었습니다.  
특히 ForeignKey를 활용한 상품-옵션 관계 설정과 역참조 부분이 가장 어려웠습니다.  
또한 URL 패턴 순서에 따라 다른 View가 실행되는 문제를 디버깅하면서 Django URL 동작 방식도 이해할 수 있었습니다.  
아쉬운 점은 예외 처리와 코드 구조를 더 깔끔하게 정리하지 못한 부분입니다.
