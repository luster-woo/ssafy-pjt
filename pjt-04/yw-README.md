PJT 04 - 영화 정보 관리 서비스
이번 프로젝트에서는 Django를 활용한 기본적인 CRUD 기능 구현과 데이터베이스 모델 설계에 집중하여 영화 정보 관리 서비스를 제작하였습니다.

1. 주요 구현 기능
영화 데이터 관리(CRUD): 영화의 제목, 줄거리, 감독 이름을 등록하고 수정, 삭제할 수 있는 기본적인 기능을 구현했습니다.

UI/UX 디자인: Bootstrap을 활용하여 영화 목록(Index)과 상세 페이지(Detail)를 깔끔하고 직관적으로 구성했습니다.

데이터베이스 설계: 영화 정보를 효율적으로 관리할 수 있도록 모델을 설계하고 마이그레이션을 통해 DB에 반영했습니다.

2. 개발 중 직면한 문제 및 대처
외부 API 연동 시도: 당초 위키피디아와 OpenAI API를 연동하여 감독 정보를 자동 생성하는 기능을 시도하였으나, API 사용량 제한(Quota Exceeded) 및 인증 문제로 인해 실시간 데이터를 가져오는 데 어려움이 있었습니다.

기능 조정: 프로젝트의 안정적인 작동을 위해 심화 기능인 AI 자동 생성 부분은 제외하였으며, 대신 기본적인 영화 정보 관리의 완성도를 높이는 방향으로 프로젝트를 마무리하였습니다.

3. 느낀 점
외부 API를 프로젝트에 도입할 때 API의 할당량이나 보안 설정 등 고려해야 할 변수가 많다는 것을 학습했습니다.

이번에는 비록 심화 기능을 완전히 구현하지 못했지만, Django의 핵심 로직과 데이터 흐름을 다시 한번 탄탄하게 다질 수 있는 계기가 되었습니다. 추후 환경이 갖춰진다면 API 연동 기능을 보완해보고 싶습니다.
