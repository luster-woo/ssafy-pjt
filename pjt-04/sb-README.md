# README

## 프로젝트 소개

이번 프로젝트는 Django의 기본 구조를 직접 적용해 보고 CRUD와 브랜치 활용 과정을 익히는 경험이었습니다.

## 어려웠던 점

처음에는 `models.py`, `forms.py`, `urls.py`의 역할을 구분하는 것이 가장 어려웠습니다.  
어떤 코드를 어디에 작성해야 하는지 헷갈려서 구조를 이해하는 데 시간이 걸렸습니다.

## 힘들었던 점

작은 오류 하나로도 기능이 동작하지 않을 때가 많아 답답했습니다.  
특히 에러 메시지를 읽고 원인을 찾는 과정이 쉽지 않았지만, 그만큼 많이 배울 수 있었습니다.
특히 url -> view -> html로 하나씩 찾아가는 과정이 어렵고 또 구현하기 힘들었습니다.

## 배운 점

이번 프로젝트를 통해 기능 구현만큼이나 전체 구조와 데이터 흐름을 이해하는 것이 중요하다는 점을 느꼈습니다.  
반복해서 수정하고 확인하는 과정 속에서 Django에 조금 더 익숙해질 수 있었습니다.

## 느낀 점

아직 부족한 부분은 많지만 직접 부딪혀 보면서 웹 개발의 흐름을 이전보다 더 구체적으로 이해하게 되었습니다.  
초보 개발자에게 쉽지 않은 과정이었지만, 그만큼 성장할 수 있었던 의미 있는 경험이었습니다.  
앞으로는 단순히 결과를 만드는 것에 그치지 않고, 왜 이렇게 동작하는지까지 스스로 설명할 수 있는 개발자가 되고 싶다고 느꼈습니다.
